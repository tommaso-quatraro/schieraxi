# Marchio: versioni senza nome

Il simbolo (10 cerchi + il capitano lime, griglia 120x120) non contiene scritte, quindi non cambia se cambia il nome.
Si rigenerano tutti con `.venv\Scripts\python.exe prove\crea_marchio.py` (stesse coordinate di `prove\crea_icone.py`; non modificare i file a mano).

| File | Uso |
|---|---|
| `simbolo.svg` | solo simbolo, senza sfondo, per fondi chiari |
| `simbolo-nero.svg`, `simbolo-bianco.svg` | monocromo (documenti, timbri, fondi scuri o colorati) |
| `app-store-1024.png` | icona App Store: opaca, senza angoli arrotondati |
| `google-play-icona-512.png` | icona Google Play |
| `google-play-primo-piano-1024x500.png` | grafica in primo piano Google Play (solo simbolo) |
| `social-og-1200x630.png` | anteprima link (Open Graph): lo spazio a destra è per il nome |
| `avatar-800.png` | foto profilo social, con margine per il ritaglio a cerchio |

Versione con testo: segnaposto, da fare quando il nome è deciso (nome a destra del simbolo nell'immagine social, logo orizzontale).
Regole d'uso: `MARCHIO.md` e `TRADEMARKS.md`.
